# Desafio_LH_Nautical
Desafio técnico do Lighthouse, programa de trainee da Indicium AI, baseado em dados operacionais de uma empresa de varejo náutico. O projeto envolve a limpeza e modelagem de 24 bases CSV (2020–2026), SQL, Engenharia de Dados, geração de insights preditivos e sistemas de recomendação.
